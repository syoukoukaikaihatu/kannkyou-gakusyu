# Circular Business Learning OS v4.4

## コンセプト
「毎日30分」ではなく、**週3回・1回最大30分**。追いつくことより継続を優先する学習OSです。

基本の週目標は、廃棄物 ×1、経営者育成 ×1、農業・余熱 ×1。曜日は固定せず、15分でも完了可。できなかった週は翌週へ宿題として繰り越しません。

## このサイトが担当するもの
- 廃棄物処理業の体系学習
- 農業の体系学習
- 余熱×農業の新規事業研究
- ChatGPT学習プロンプトのコピー
- 学習結果の一括貼り付け
- 会社の現在地（OUR FACT / ISSUE / UNKNOWN）の蓄積
- 必要なテーマだけ社内共有資料プロンプトを作成

経営者育成は別の Executive Daily Development で週1回を目安に運用します。

## 1回の流れ
1. HOMEで今日の分野を1つ選ぶ
2. 学習プロンプトをコピー
3. ChatGPTで15〜30分学習
4. [SITE_DATA] をコピーしてサイトへ貼る
5. 保存して完了

仕事の中で同じテーマを調査・検討した場合も、その分野の学習1回として扱って構いません。

## 保存
データはブラウザの localStorage に保存されます。定期的にJSONバックアップを推奨します。
