# Circular Business Learning OS v4.3

毎日30分、ChatGPTで「廃棄物」「農業」「余熱×農業」を学び、学習進捗と会社理解を一元管理するシンプルな学習OSです。

## 毎日の使い方
1. HOMEから今日のテーマを選ぶ
2. 「ChatGPT学習プロンプトをコピー」
3. ChatGPTに貼り、約30分対話学習
4. 最後にChatGPTが出す `[SITE_DATA]` ブロックをコピー
5. サイトの「ChatGPTからコピーした内容」に貼り「反映」
6. 内容を確認し「保存して完了」

## 自動で蓄積するもの
- 学習進捗
- 学習記録（KNOWLEDGE）
- OUR FACT：自社について確認できた事実
- ISSUE：会社の課題候補
- UNKNOWN：まだ分からない・次に確認すること
- SOURCE：根拠・参考資料

「会社の現在地」画面は各学習記録から自動集約するため、原則として別入力は不要です。

## 保存
ブラウザの localStorage に保存します。v4.1以前の保存データを可能な範囲で引き継ぎます。同じURL・同じブラウザでの利用を基本とし、定期的にJSON書き出しでバックアップしてください。


## 社内共有資料
学習記録の各テーマに「共有資料」ボタンを追加しています。必要なテーマだけ選び、保存済みの KNOWLEDGE / OUR FACT / ISSUE / UNKNOWN / SOURCE を含むChatGPT用プロンプトをコピーできます。

標準出力は「A4 1枚・3分で読める社内共有資料」です。ChatGPTには、テーマ・結論、重要ポイント、自社との関係、確認済み事実、課題・検討事項、次に確認すること、根拠・出典の順で整理させます。全テーマを資料化するのではなく、社内展開したいテーマだけ使う想定です。
