# Waste Management Executive v3.0

廃棄物処理・工場経営について、学習、現場確認、資格・設備・行政・経営課題、12か月育成ロードマップを一元管理するサイトです。

## v3.0
- 12か月ロードマップをサイト内で完全管理
- 月ごとの状態（未着手／進行中／完了）
- 月次進捗率
- 今月できるようになったこと
- 現場で確認したこと
- 次に確認・改善すること
- 経営陣への月次共有済みチェック
- 完了月数・平均進捗・共有済み月数を自動集計
- v2のlocalStorageデータを自動引継ぎ

日常運営は、このサイト＋ChatGPTを中心に行い、別Excelでロードマップを管理する必要はありません。
