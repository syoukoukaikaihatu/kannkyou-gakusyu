# Waste Management Executive v3.1

## 運営コンセプト
このサイトは「廃棄物処理・工場を理解する」ための専門学習OSです。
Executive Daily Development（経営者育成）とは役割を分けます。

- 工場経営研修：知識、現場事実、設備、資格、人材、操業、行政、原価、課題候補を把握
- MANAGEMENT BRIDGE：経営側で検討すべき重要論点だけを抽出
- 経営者育成：投資、人事、戦略、優先順位など「どう経営判断するか」を検討

## v3.1の主要機能
1. HOMEの3入口
   - 今日の研修
   - 現場30秒メモ
   - 今日の振り返り
2. QUICK CAPTURE
   - スマホで短時間入力
3. INBOX
   - 未整理メモを週1回まとめて振り分け
   - KNOWLEDGE / 設備MAP / 資格・人材MAP / ACTION / MANAGEMENT BRIDGEへ一度の入力から反映
4. KNOWLEDGE / OUR FACT / ISSUE の3分類
5. KNOWLEDGE MAP
   - Lv0〜Lv5で理解度を可視化
6. MANAGEMENT BRIDGE
   - 工場側では解決策を作り込みすぎず、重要な経営論点だけをストック
7. 研修記録の簡素化
   - 「今日わかったこと」「自社ではどうか」「現場で確認すること」の3項目を基本入力
8. 12か月ロードマップは引き続きサイト内管理
9. v3のlocalStorageデータを自動引継ぎ

## 保存
データはブラウザのlocalStorageに保存されます。同じURL・同じブラウザでの利用を基本とし、定期的にJSON書き出しでバックアップしてください。
