# Circular Business Learning OS v4.1

目的は「毎日30分、ChatGPTで学ぶこと」です。サイトは学習そのものを行う場所ではなく、テーマ選択・専用プロンプト出力・学習結果の記録・進捗確認に絞りました。

## 画面
- HOME：廃棄物／農業／余熱×農業の3入口と進捗
- 廃棄物：24テーマ
- 農業：16テーマ
- 余熱×農業：8テーマ
- 学習記録：全テーマの記録を一元表示

## 1日の運用
1. HOMEから今日の分野を選ぶ
2. テーマを開く
3. 「ChatGPT学習プロンプトをコピー」
4. ChatGPTへ貼り付けて約30分学習
5. 最後にChatGPTが出す4項目をサイトへ記録
6. 「保存して完了」

## 削除した考え方
成長記録、INBOX、30秒メモ、資格MAP、設備MAP、会議、ACTION等は日々の学習OSとしては複雑になるためメイン導線から外しました。

## データ
localStorage保存です。v3.1の廃棄物学習完了・学習メモは可能な範囲で自動移行します。端末間同期はしません。定期的に「バックアップ」でJSON保存してください。
